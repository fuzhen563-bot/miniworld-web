## ✨ 功能特性

### 🌍 无限程序化世界
- fBM 值噪声地形：山脉、平原、海洋、沙滩、雪原自然过渡
- 洞穴系统、煤矿、铁矿随机分布，基岩封底
- 树木、花草自动装饰，无限延伸（区块按需生成 + 自动卸载）
- 昼夜循环（20 分钟/天）：天空渐变、黄昏晚霞、日月轮转、云朵漂移

### 🎮 双模式玩法
| | 🏗️ 创造模式 | 🛡️ 生存模式 |
|---|---|---|
| 破坏 | 瞬间拆除 | 长按挖掘 + 工具需求 |
| 资源 | 无限取用 | 挖掘掉落、拾取收集 |
| 生命 | 无 | ❤️ 血量 + 🍗 饥饿值 |
| 移动 | 双击空格飞行 | 跳跃 / 游泳 / 疾跑 |

### 🛠️ 完整进度链
```
撸树 → 木板 → 木棍 → 木镐/木斧/木铲/木剑
              ↓
        挖石头 → 圆石 → 熔炼（煤炭燃料）
              ↓
   沙子 → 玻璃 · 原木 → 木炭 · TNT · 荧光石
```
- 树叶掉落 🍎 苹果（右键长按进食恢复饥饿）
- 💣 TNT：打火石点燃 → 引信音效 → 连锁爆炸 + 冲击伤害

### 🎥 沉浸体验
- **三种视角**（按 `V` 切换）：第一人称 / 第三人称身后 / 第三人称正面
- 方块小人角色：行走摆臂、身体起伏动画
- 第一人称手持物品 + 挥动动画
- 破坏进度遮罩、碎块粒子、掉落物浮动拾取
- 🔊 WebAudio 实时合成音效（挖掘/脚步/爆炸/进食/拾取…，无需音频文件）
- 受伤红屏闪烁、水下滤镜、夜间氛围光

### 💾 存档系统
- RLE 压缩区块存档（压缩率 ~60%），localStorage 持久化
- 每 30 秒自动保存 + 关闭页面自动保存
- 主菜单一键继续上次进度

## 🚀 快速开始

### 方式一：直接打开（最简单）
```bash
# 克隆后双击 index.html 即可（file:// 协议可运行）
git clone [https://github.com/fuzhen563-bot/miniworld-web](https://github.com/fuzhen563-bot/miniworld-web).git
```

### 方式二：本地服务器（推荐）
```bash
cd miniworld-web

# 任选其一
python -m http.server 8000
npx serve .
```
浏览器访问 `http://localhost:8000`

### 环境要求
| 条件 | 说明 |
|---|---|
| 浏览器 | Chrome / Edge / Firefox / Safari 15+（需支持 **WebGL2**） |
| 依赖 | **无**。零 npm 包、零构建步骤 |
| 服务端 | 不需要，纯前端静态文件 |

## 🏗️ 技术架构

**纯手写渲染管线，无任何游戏引擎。**

```
miniworld/
├── index.html          # 页面骨架 + 全部 UI（主菜单/HUD/合成/背包）
├── style.css           # 像素风 UI 样式
└── js/
    ├── noise.js        # 值噪声 + fBM（可播种，地形生成核心）
    ├── blocks.js       # 方块/物品定义 + 程序化 16×16 像素纹理工集
    ├── terrain.js      # 地形生成：高度场/洞穴/矿脉/树木/花草
    ├── world.js        # 16×96×16 区块存储、懒生成、TNT 调度
    ├── mesher.js       # 区块网格：隐藏面剔除、水面、双面十字花草
    ├── player.js       # AABB 物理、逐轴碰撞、DDA 射线、饥饿系统
    ├── inventory.js    # 背包（快捷栏+27格）、配方表、熔炼表
    ├── extras.js       # 相机视角/角色模型/手持物品/天空/音效
    └── main.js         # WebGL 渲染器 + 游戏主循环 + UI + 存档
```

### 关键技术点

| 模块 | 实现 |
|---|---|
| 渲染 | WebGL2 + GLSL：面剔除合并网格、昼夜光照 uniform、距离雾、水面顶点波动 |
| 纹理 | 全部材质运行时程序化生成（矿石斑点、圆石 voronoi、水波等），单图集采样 |
| 性能 | 每帧预算：≤3 区块生成 + ≤4 区块重建；邻居列缓存避免重复查找；远处自动卸载 |
| 物理 | 逐轴扫掠碰撞（贴墙平滑移动）、摔落伤害、浮力游泳 |
| 拾取 | DDA 体素射线（Amanatides & Woo 算法） |
| 存档 | 列式 RLE + Base64，localStorage ~5MB 上限下可存大量区块 |
| 音效 | WebAudio API 实时合成噪声/振荡器，零资源文件 |

## ❓ FAQ

**Q: 打开后提示"需要 WebGL2 支持"？**
A: 请使用最新版 Chrome/Edge/Firefox，并确认未禁用硬件加速。

**Q: 画面很卡？**
A: 渲染视距为 11 区块（约 176 格），低配设备可在 `main.js` 中调小 `updateChunks()` 里的 `R` 值。

**Q: 存档存在哪里？**
A: 浏览器 localStorage（键名 `miniworld.save.v3`），清除浏览器数据会丢失存档。

**Q: 可以商用吗？**
A: 代码为 MIT 协议可自由使用；请注意"迷你世界"为深圳迷你玩商标，本项目仅为技术学习致敬，请勿用于商业发行。
